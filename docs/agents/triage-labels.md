# Triage 标签

各技能以五个规范 triage 角色来表述。本文件将这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                           |
| -------------------------- | ------------------ | ------------------------------ |
| `needs-triage`             | `needs-triage`     | 维护者需要评估该 issue         |
| `needs-info`               | `needs-info`       | 等待报告者补充信息             |
| `ready-for-agent`          | `ready-for-agent`  | 已完全规格化，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                   |
| `wontfix`                  | `wontfix`          | 不予处理                       |

当技能提到某个角色（如 "apply the AFK-ready triage label"）时，使用本表中对应的标签字符串。

如需改用实际使用的词汇，编辑右列即可。
