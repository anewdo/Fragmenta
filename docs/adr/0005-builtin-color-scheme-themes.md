# 主题模式与内置色系主题并列

gpui-kit 自带 20 套主题与 JSON 自定义主题机制，但均不采用。定案：`ThemeMode` 在 Light / Dark / Auto 之外并列若干内置色系主题（豆沙绿等），每套定义 ~8 个核心颜色 token（背景 / 面板 / 标题栏 / 边框 / 前景 / 强调色等），其余继承 Light 基线；用户仅选择预设，不做逐区域调色、不做主色派生、不暴露 JSON 文件。理由：与"轻量、美观"定位相符，用户零负担，效果完全可控。色系主题与 Auto 互斥（Auto 仅代表跟随系统 Light/Dark 切换）；具体预设清单与色值在实施期以候选方案交用户挑选（架构 §1 流程）。否决 20 套 kit 主题选择器：多数用不上且风格不可控；否决主色自动派生：派生效果需见实物方可裁决，留作后续增强（枚举预留扩展位）。
