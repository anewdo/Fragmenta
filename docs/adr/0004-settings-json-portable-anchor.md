# settings.json 永驻 exe 旁作为数据目录定位线索

数据目录可热迁移意味着启动时 exe 无从得知其位置，定位线索必然存在于数据目录之外。备选：注册表 / %APPDATA%（重装系统与换机即丢线索，应用回落默认目录，用户数据"看起来全丢了"，是随记应用最坏故障模式）vs settings.json 永驻 exe 旁（便携锚点，换机拷走 exe 旁这一个文件即完整恢复）。选后者：牺牲"exe 旁零文件"的观感，换取线索永不因系统级变更丢失。数据目录内部保持平铺——`fragmenta.db` 与 `imgs/` 同级，不再细分 `data/` 子文件夹；settings.json 是唯一例外，不入数据目录。
