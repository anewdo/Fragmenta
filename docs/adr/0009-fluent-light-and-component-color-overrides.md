# Fluent 风格、Light 打磨与组件颜色覆盖

Fragmenta 以 Fluent 为主要视觉参考，先打磨白色背景为主的 Light，范围覆盖主窗口与磁贴，保持现有页面结构。背景层次、文字对比、按钮、输入框、菜单、选中态、边框与阴影采用统一规则；尺寸、文字角色与布局档位继续遵循 ADR-0007。

Light 的内容区以白色为主，侧栏与标题栏采用接近白色的中性色，菜单与对话框通过细边框和轻阴影区分层级。主窗口与磁贴的 Light 标题栏采用纯色。强调色以蓝色为方向，候选主色为 `#0F6CBD`，具体色值在实际界面的视觉验证中微调；分类、标签已有的用户颜色继续保留。

主要按钮采用蓝底白字，普通按钮采用白底、细边框和深色文字，图标与工具按钮默认透明、悬停时出现浅色底。导航与笔记选中项采用淡蓝底，配合蓝色指示或边框；未选中项悬停采用较轻的中性色反馈。

首阶段提供 Light、Dark 与 Auto，设置页保留主题切换能力。Light 优先完成视觉打磨，Dark 通过新架构加载并沿用当前基线配色；Auto 根据系统外观在二者之间切换。Light 完成后，再通过新架构逐套设计并添加色系主题。

内置主题以 JSON 定义，复用 kit 的主题加载机制。首阶段 JSON 管理配色与阴影，圆角、字号、间距和布局宽度继续使用现有尺寸令牌。开发时支持修改文件即时预览，发布时将主题 JSON 在编译期嵌入 EXE，主题资源随单个可执行文件分发。这使主题开发能集中调整视觉定义，并沿用框架已有的加载与监听能力。

Light 与 Dark 从首阶段统一通过 JSON 定义与加载。移除 `theme_schemes.rs`、豆沙绿与天空蓝的旧配色定义及主题入口，主题模式收敛为 Light、Dark、Auto。后续色系主题在 Light 的视觉规则与组件角色基础上重新设计。

后续允许用户在设置中按组件角色覆盖部分颜色，同类角色在各页面统一生效，覆盖按具体主题分别保存。内置主题提供默认配色，用户设置保存修改项；重新加载主题后重新应用对应覆盖。独立角色之间保持配色边界，例如主要按钮底色与链接、聚焦环分别调整。用户可调整的角色与颜色属性在后续设计中确定，组件调色设置随后实现。

状态：accepted（2026-10-25）；更新 ADR-0005 中内置主题定义方式与用户调色范围的约定。
